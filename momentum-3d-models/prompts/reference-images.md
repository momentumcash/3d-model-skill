# Reference image prompts

Fill the [brackets] from BRIEF.md and STYLE.md. Make all three in the same chat so the style stays the same. Attach your best style reference to each one.

## 1. Hero view
```
A single [object] for a Roblox game, [one-line style from STYLE.md].
3/4 view from slightly above, the whole object in frame, centred.
Plain light grey background, soft studio light, no shadow clutter, no text, no logo, no other objects.
Colours: [palette hexes]. Hero features: [the 3 hero features].
```

## 2. Turnaround sheet
```
Character-sheet style turnaround of the exact same [object] from the image above.
Four views in a row, same scale, same height line: front, side, back, top.
Orthographic (no perspective), plain light grey background, no text labels, no shadows.
Keep every detail, colour and proportion identical to the hero image.
```

## 3. Exploded view
```
Exploded view diagram of the exact same [object]: every separate part pulled apart along clean lines,
floating in place so you can see how they fit together. Same style and colours as before.
Plain light grey background, no text, no arrows, no labels.
```

Save them as refs/hero.png, refs/turnaround.png, refs/exploded.png.
